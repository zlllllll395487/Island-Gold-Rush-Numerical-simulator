# 总览图表定稿设计

## 目标

总览保留地图主视觉，并用四张明确回答策划问题的图替代难以理解的累计线和玩家散点图。

## 布局

- 主视觉行：战局地图 + 联盟相对平均分差。
- 分析行：战斗与占领事件 + 战力与活跃分层贡献 + 玩家积分贡献集中度。
- 宽屏三张分析图等宽排列；窄屏自动换行。

## 图表口径

- 联盟相对平均分差：每个联盟总分减去同一时刻三联盟平均分，展示领先幅度。
- 战斗与占领事件：保留现有每小时战斗、占领与小时场均战功。
- 分层贡献：按战力档位与活跃档位聚合当前回放时刻的玩家总积分与人均积分。
- 贡献集中度：玩家按当前积分从高到低排序，展示前 X% 玩家贡献的累计积分占比。

## 交互

四张图均随全局回放时间变化；不新增独立筛选器。
