# GitHub Pages 静态部署设计

日期：2026-08-19
状态：已获用户批准

## 目标

将“海岛夺金 数值模拟”直接部署到 GitHub Pages，生成一个任何人无需登录即可打开的公开链接：

`https://zlllllll395487.github.io/Island-Gold-Rush-Numerical-simulator/`

发布版本必须保留完整交互功能：参数调整、随机重新仿真、按种子复现、地图时间轴回放、积分趋势、玩家积分流水、任务奖励、排名和批量实验。

## 方案选择

采用“独立静态 Vite 入口 + GitHub Actions Pages 发布”。

现有 Vinext/Worker 构建继续保留，用于本地开发和原生产构建验证；新增的 Pages 构建只负责公开静态站点。模拟器的运算、状态和数据均已在浏览器端完成，因此静态入口可以复用同一套 React 组件和仿真模块，无需服务器 API。

不采用以下方案：

- Cloudflare Workers：需要额外账号授权，不符合“直接 GitHub 部署”的目标。
- 仅上传源码：不能提供可直接使用的网页。
- 把 SSR 输出 HTML 进行字符串改写：路径和水合行为脆弱，维护成本高。

## 架构

### 静态入口

新增一个轻量 HTML 入口和 React 挂载文件。挂载文件直接渲染现有 `SimulationDashboardV2`，不复制业务逻辑。

### 独立构建配置

新增 GitHub Pages 专用 Vite 配置：

- `base` 固定为仓库路径 `/Island-Gold-Rush-Numerical-simulator/`；
- 只启用标准 React 插件；
- 输出到独立目录，避免覆盖 Vinext 的 `dist`；
- 复用现有组件、样式、地图数据和公共图片。

### 自动部署

新增 GitHub Actions 工作流：

1. 检出 `main`；
2. 安装 Node.js 22；
3. 使用 `npm ci` 安装锁定依赖；
4. 运行静态 Pages 构建；
5. 上传构建产物；
6. 发布至 GitHub Pages。

工作流只使用 GitHub 官方 Pages Actions，不写入任何 token、内部地址或额外平台凭据。

## 数据与功能边界

- 所有仿真均在访问者浏览器内运行。
- 不上传真实玩家数据，不调用内部接口。
- 刷新页面会回到默认参数；本阶段不增加服务端存储。
- 随机种子仍在每次“运行仿真”时生成，复现按钮保持现有语义。
- 静态站与现有本地版本共享同一源码，避免两套模拟规则分叉。

## 错误处理

- 构建失败时 GitHub Actions 停止发布，线上保留上一成功版本。
- 静态资源路径必须基于仓库子路径生成，防止页面打开但脚本或图片 404。
- 页面启动失败时在挂载节点显示简洁错误信息，便于定位浏览器兼容问题。

## 测试与验收

先写失败测试，再实现静态部署层。验收包括：

1. Pages 配置使用正确仓库子路径；
2. 静态入口实际挂载 `SimulationDashboardV2`；
3. 构建产物包含 `index.html`、JS、CSS、地图与站点图片；
4. 产物中的资源链接带正确 Pages 基础路径；
5. 现有 132 项测试继续通过；
6. lint、Vinext 生产构建和 Pages 静态构建全部通过；
7. GitHub Actions 发布成功后，公开 URL 返回页面且无需登录；
8. 页面可修改参数并重新运行仿真。

## 公开内容约束

仓库和部署产物只保留模拟器本身、通用玩法介绍、示例地图、测试和公开迭代记录。不得包含飞书链接、本机绝对路径、内部机器人目录、真实数据、凭据、token 或其他项目代码。
