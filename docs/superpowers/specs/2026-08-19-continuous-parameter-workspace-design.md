# 海岛夺金数值模拟：连续参数工作区设计

## 目标

在保留当前克制、编辑化视觉语言的基础上，解决参数编辑区拥挤、具体参数缺少结构、主要结果依赖页签切换的问题。最终页面应让策划能快速定位参数、连续浏览全部配置，并在同一结果页理解地图、指标和图表。

## 页面结构

### 顶部横向导航

- 品牌标记与“海岛夺金 · 数值模拟”位于最左侧。
- 六个功能入口横向排列：仿真总览、行动力与占领、战斗与士气、任务与奖励、玩家与联盟排名、批量实验。
- 当前种子复现与运行仿真位于最右侧。
- 顶栏固定于页面顶部，不占用参数侧栏宽度。

### 参数工作区

- 左侧只保留“参数调整”、搜索、恢复默认和 11 个分类目录。
- 右侧为一张连续参数页面，全部 120 个参数从上到下展示。
- 不使用下拉、折叠、手风琴或一次只显示一个分类的页签。
- 点击左侧分类时，右侧平滑滚动至对应章节；滚动时同步更新当前分类。
- 搜索只过滤参数行，不改变连续章节结构。

## 参数排版

- 分类章节使用标题、简短说明、参数数量和浅分隔线，不使用外围卡片。
- 普通参数采用横向行：参数名及说明在左，输入控件和值在右。
- 数字输入右对齐、使用等宽数字；输入框保持透明或纸面色，仅保留轻边线/底线。
- 比例与范围使用滑杆加精确数值输入；离散数字只使用数字输入。
- “人口与战力”按四个玩家档位组织为矩阵，列为玩家占比、基础战力、战力波动、主力编队数、普通编队强度。
- 任务 1～10 使用统一表格，每个任务一行，避免重复的窄列小表单。
- 所有既有校验、恢复默认、搜索、不可变配置更新和参数路径保持不变。

## 主要结果页

- 主要内容不使用下拉或折叠隐藏。
- 采用分块式布局：地图作为最大区块；关键指标、占领与战斗摘要、联盟积分比较、玩家分布、排名等作为相邻的轻量区块。
- 各区块通过留白、标题层级和细分隔线区分，不使用高阴影或大量深色卡片。
- 只有地图区域使用大面积深色背景；图表和表格保持低视觉重量。
- 页面总长度控制在约 1.5～2 个桌面视口，优先通过网格并排而不是折叠内容节省空间。

## 响应式行为

- 桌面端：顶部横向导航；参数目录固定在左，连续参数正文独立滚动。
- 窄屏：顶部导航允许横向滚动；参数目录变成正文上方的横向锚点栏；参数表格允许横向滚动或转换为单列参数行。
- 不隐藏关键配置或结果，所有功能保持可访问。

## 验收标准

- 六个功能入口只存在于顶部横向导航。
- 参数页同时渲染全部 11 个分类，不需要点击切换内容。
- 左侧分类点击可定位右侧章节，且不存在 `details`、`summary` 或折叠控件。
- 人口与战力、任务奖励分别呈现为可读矩阵/表格。
- 主要结果页的核心地图、指标和图表无需展开即可看到。
- 现有 120 个参数均可编辑，校验、运行、恢复默认和搜索行为不回归。
- 桌面与窄屏均无不可达控件、遮挡或不必要的双层页面滚动。

## 测试策略

- 组件测试覆盖 11 个章节同时渲染、分类锚点定位、搜索过滤、任务表格、人口矩阵及无折叠控件。
- 仪表盘测试覆盖顶部导航、主要结果分块、参数草稿与已应用配置隔离。
- 运行完整测试、lint、生产构建和 GitHub Pages 产物校验。
