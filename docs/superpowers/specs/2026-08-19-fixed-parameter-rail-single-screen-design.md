# 常驻参数目录与单屏结果区设计

## 目标

将现有“宽参数面板 + 纵向结果报告”重构为“常驻参数目录 + 临时配置抽屉 + 单屏结果区”。保留当前编辑型美术风格、字体层级、细线分隔、克制配色和六边形地图视觉。

## 页面结构

- 顶部横条继续承载品牌、六个功能入口、种子复现和运行仿真。
- 顶部横条下方固定一条 `158px` 的参数类别目录。
- 参数目录包含 11 个类别和各自参数数量；类别名称与数量均保持单行。
- 主结果区占据目录右侧全部可用宽度，不因参数配置而永久缩窄。
- 点击参数类别时，从目录右侧弹出 `430px` 的配置抽屉。
- 抽屉覆盖主结果区，不参与主网格宽度计算；关闭后主结果区无需重新布局。

## 参数交互

- 参数目录始终可见，当前类别使用青绿色短标记和加重文字表示。
- 点击任意类别会打开抽屉，并将抽屉内容替换为该类别的参数。
- 抽屉只渲染当前类别，不再一次纵向铺开全部 120 项参数。
- 抽屉顶部包含当前类别名称、说明、搜索、恢复默认和关闭操作。
- 点击遮罩、关闭按钮或按下 Escape 关闭抽屉；目录保持可见。
- 抽屉内不使用 `details`、`summary`、下拉分类器或折叠面板。
- 人口与战力使用四档矩阵，任务与奖励使用 10 行紧凑表格；必要时只允许表格内部横向滚动。
- 用户修改仍写入 `draft`，只有“运行仿真”才更新 `applied` 结果。

## 单屏结果区

- 仿真总览在常见 1080p 桌面高度内集中展示，不再组织成长清单。
- 顶部保留 4 个关键指标。
- 地图高度缩小至约 `min(40vh, 430px)`，作为主视觉但不独占首屏。
- 地图右侧显示当前战况：领先联盟、中心争夺强度、高价值地格。
- 地图下方同一行展示联盟积分差和玩家战力分布。
- 其他功能标签继续切换各自结果页面，不使用页面内折叠。

## 响应式

- 宽度大于 `900px`：目录常驻、抽屉覆盖、结果区单屏分块。
- 宽度不大于 `900px`：目录改为横向可滚动类别条，抽屉从左侧覆盖；结果模块允许自然纵向排列。
- 所有类别名称、关键指标名称和主要操作保持单行；极长说明文字可换行。

## 可访问性与验证

- 参数目录使用带名称的 `navigation`，类别按钮使用 `aria-current` 表示当前类别。
- 抽屉使用 `role="dialog"`、`aria-modal="true"` 和可访问标题。
- 打开抽屉后焦点进入搜索框；关闭后焦点回到触发类别。
- 新增组件测试覆盖目录常驻、抽屉打开/切换/关闭、无折叠元素、draft/applied 隔离和单屏布局契约。
- 保持现有仿真、回放、积分流水、地图和发布构建测试全部通过。

## 非目标

- 不改动仿真算法、数值默认值或地图数据。
- 不改变现有视觉品牌与颜色体系。
- 不新增第三方 UI 依赖。
- 本轮不推送 GitHub，待用户本地验收后再部署。
