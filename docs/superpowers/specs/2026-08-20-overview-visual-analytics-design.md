# 海岛夺金总览可视化增强设计

## 目标

将“仿真总览”升级为单屏分析页面。地图仍是主视觉，配合三张足够大的分析图，减少说明文字，并让玩家能够从图形直接理解战局进程、战斗强度和玩家贡献结构。

## 页面结构

采用两行双栏布局，不增加额外纵向滚动：

1. 第一行左侧为地图回放，右侧为战斗节奏图。
2. 第二行左侧为战局走势图，右侧为玩家贡献散点图。

地图区域不再使用超宽画布，改为接近 4:3 的有效绘图区，减少黑色空白并放大六边形地图本体。

## 地图回放

- 保留回放滑块，并作为全页唯一时间控制器。
- 提供“联盟占领 / 战斗热力 / 地格价值”三个显示模式。
- 联盟占领模式展示当前归属、地形、交战和队列。
- 战斗热力模式按截至当前时刻的地格战斗次数映射颜色强度。
- 地格价值模式突出地格积分价值，并保留联盟归属轮廓。

## 当前战斗指标

不再保留独立的高空白右栏。三项指标进入战斗节奏图标题区：

- 总战斗次数：截至当前时刻已经结束的战斗场次。
- 每场战斗平均积分：截至当前时刻产生的战功积分总和 ÷ 已结束战斗场次，不包含占领积分；无战斗时显示 0。
- 排名变化次数：三个联盟按总分排序后的顺序发生变化的次数。初始排序不计变化；同分时使用联盟 ID 作为稳定次序。

## 三张分析图

### 1. 战局走势

- 三联盟折线图，可切换“联盟积分 / 占领价值”。
- 显示坐标轴、网格、当前时间游标和末端标签。
- 发生联盟排名变化的时刻显示节点。
- 数据只展示当前回放时刻及之前，避免泄漏未来结果。

### 2. 战斗节奏

- 按小时展示战斗次数与占领次数柱形。
- 叠加每场战斗平均战功积分折线。
- 标记首次 PvP 时刻。
- 标题区同时展示总战斗次数、平均积分和联盟排名变化次数。

### 3. 玩家贡献散点图

- 横轴为玩家战力，使用对数尺度，避免超级大 R 压扁其他玩家。
- 纵轴为行动力使用率。
- 气泡面积代表个人总积分，颜色代表所属联盟。
- 提供战力档位参考线和简洁图例。
- 散点图展示当前回放时刻的积分；玩家 AP 使用率采用本局结果口径，并明确标注。

## 交互与视觉

- 拖动回放滑块时，地图、战局走势、战斗节奏及当前战斗指标同步更新。
- 地图模式和战局走势模式切换不重新运行仿真。
- 采用现有编辑型美术风格：米白背景、克制线条、三联盟固定配色、衬线标题和无衬线标注。
- 图表以 SVG 实现，不引入重量级图表依赖。
- 1920×1080 下无需缩放页面即可读清坐标、图例和末端数值。

## 数据边界

- 使用现有 `snapshots`、`timeline`、`scoreEvents` 和玩家结果派生数据。
- 不增加仿真时间步，不改变随机行为或战斗结果。
- 新增独立的回放聚合模块，集中计算时间序列、热力、排名变化和散点数据。

## 验收标准

- 总览保持单屏主体，不新增约一屏的纵向内容。
- 地图实际内容明显放大，超宽黑色空白明显减少。
- 三张图均具有可读坐标轴、图例和当前时刻状态。
- 三项战斗指标与回放时刻同步，且具有零战斗和排名同分边界测试。
- 所有时间图只展示当前时刻及之前的数据。
- 原有参数调整、随机仿真、复现、排行和玩家积分流水功能保持可用。
